PRODUCT BLUEPRINT
BIZ-SIGNAL-AGENT

商机信号的个性化泛化推演引擎

把一个抽象的外部商机词，翻译成 N 个真实买家身份下可执行的搜索 / 选品方向。 传统词向量扩展无法做到的"基于人格的视角分化"，在多 agent 仿真中自然涌现。

CORE PIPELINE
输入 → 推演 → 输出
INPUT
两个极简输入
USER ID
buyer_id: 89215...
真实 1688 买家
SIGNAL
外部商机信号词
如"新中式" / "巴恩风" / "宋代美学"
推演引擎 · Multi-Agent Simulation
三阶段串行 — 身份激活 / 同行交互 / 共识收敛
7 agents qwen-plus
STAGE 01
身份激活
每个 agent 加载自身 30 天真实行为画像后，独立给出对该商机词的初始判断与衍生表达，确保 N 条声音从一开始就分化。
独立反应 · 不互相看见 · 立场 / 衍生词 / 落地 / 顾虑
STAGE 02
同行交互
每个 agent 看到其他人的发言后，基于自身身份做反对 / 补充 / 质疑三选一回应，强制非赞同型对话，避免群体观点坍缩。
DISAGREE · ADD · QUESTION · 禁止纯赞同
STAGE 03
共识收敛
多轮交互后系统聚合每个个体的稳定表达，提取群体共识词 + 稀有视角，输出商机词在每个真实身份下被细化的最终表达。
peer-rating · 共识聚合 · 稀有视角抽取
OUTPUT
个性化泛化产物
DERIVED KEYWORDS
个性化衍生搜索词集合
每词带身份标签 + 落地建议
STANCES
个体立场 + 群体分布
积极 / 观望 / 无关
DYNAMICS
共识词 / 稀有视角 / 反对意见
含每条衍生词溯源

三个核心价值
01
真实身份驱动 · 非泛化模板
每个 agent 由 30 天真实买家行为约束。Agent 的反应可被原始行为追溯,不是 LLM 在通用画像上的拟合产物。
02
多视角自然涌现 · 不交集
同一商机词在不同身份下生出几乎不交集的衍生空间。词向量 / 共现扩展给不出来的"人格化视角分化"。
03
可验证可闭环 · 可迭代
衍生词可对照 7-30 天后真实站内搜索 / 采购数据做命中率回测,形成数据闭环,持续训练强化推演引擎。
